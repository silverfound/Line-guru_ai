# Line-guru_ai

Cricket prediction project.

## Astrology prototype

Open [`astrology.html`](./astrology.html) to try the mobile-friendly astrology/planetary-position prototype. It uses Astronomy Engine in the browser to calculate approximate ecliptic longitudes for the selected match start time. Team records and player statistics are not used.

**Limitations:** this is an astrology-themed informational prototype, not a scientifically validated match prediction model. It does not produce a winner probability. The selected UTC offset must match the match venue's local time zone. The planetary calculations require an internet connection to load the library.
